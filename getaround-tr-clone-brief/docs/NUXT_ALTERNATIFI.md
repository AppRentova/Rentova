# Nuxt Alternatifi

Nuxt kullanilacaksa frontend Vue 3 tabanli olur; React kullanilmaz.

Esdeger stack:

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS
- Pinia
- VueUse
- VeeValidate + Zod
- Nitro server routes
- Prisma + PostgreSQL

React componentleri Nuxt componentlerine dogrudan tasinamaz. UI componentleri Vue single-file component olarak yeniden yazilmalidir.
